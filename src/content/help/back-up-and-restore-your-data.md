Your data lives only in this browser, so a backup is your safety net before
clearing site data, switching devices, or experimenting. Export writes a single
JSON file with everything — items, groups, lists, sessions, and photos.

## Export a backup

1. Tap **Settings** in the bottom navigation.
2. Under **Backup & restore**, tap **Export**.
3. Save the downloaded JSON file somewhere safe.

## Import a backup

1. In **Settings → Backup & restore**, tap **Import…** and choose your file.
2. Review what the file contains.
3. Choose how to apply it:
   - **Merge** — add anything that isn't already there; existing data is left
     alone.
   - **Replace** — wipe all current data, then load the file. This can't be
     undone, and the page reloads afterward.

## What you'll see

After a merge you keep everything you had plus whatever was new in the file.
After a replace, the app reloads showing exactly the file's contents. Photos
are included in the file (encoded inline), so they come back too.
