Run mode turns a saved list into a focused checklist with large tap targets.
It's called **Shop it** in Shopping, **Chore it** in Chores, and **Run it** in
Projects.

## Steps

1. Open the **Lists** card for a flavor.
2. Tap the play button on a list (or open the list and tap **Shop it** /
   **Chore it** / **Run it**).
3. Check things off as you go. In Shopping, repeated items are summed so the
   quantity is correct.
4. Reorder on the fly with the drag handles if you want a different sequence —
   this only affects the current run.
5. When you're done, tap **Wrap up**.
6. On the wrap-up screen, optionally add **Photos** and **Notes**, then save.

## What you'll see

A screen wake-lock badge keeps the display awake while you work (it's
best-effort — if your browser doesn't support it, the badge says it may sleep).
Saving on the wrap-up screen records the run to **History** with its checked
state, photos, and notes.
