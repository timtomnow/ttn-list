If you're starting Shopping from scratch, you can load a set of common grocery
items so you're not typing everything from zero. Each comes pre-tagged by
category, ready to drop into a list.

## Steps

1. Tap **Settings** in the bottom navigation.
2. Find the **Shopping** section, **Starter grocery items**.
3. Tap **Load starter items**.

## What you'll see

Around 110 grocery items are added to your Shopping library, each tagged by
category (Produce, Dairy, Cleaning, and so on). Items you already have are
skipped, so it's safe to run again — you'll just be told nothing new was added.
