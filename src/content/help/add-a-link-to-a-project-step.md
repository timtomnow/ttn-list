A project step can carry an optional **Link** — a web address you want handy
while you work, like a how-to video, a spec sheet, or a supplier page. The link
travels with the step into every list, and you can open it during a run without
losing your place.

## Before you start

- This is a **Projects** feature. Open **Projects** from the bottom bar.

## Steps

1. Tap the **Steps** card.
2. Tap **New** (or **Edit** on an existing step).
3. Fill in the **Name**.
4. In **Link (optional)**, paste or type a web address — for example,
   *https://example.com/guide*. If you leave off `https://`, it's added for you.
5. Optionally add **Notes**, **Tags**, and a **Photo**.
6. Tap **Save**.

## What you'll see

Steps that have a link show a small link icon next to their name in the library.
When you **Run it** on a list containing that step, a blue link icon appears
beside the step. Tap it to open the link in a new browser tab — this does **not**
check the step off. Tap the step's text as usual to check it off.
