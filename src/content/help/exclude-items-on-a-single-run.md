Sometimes you want a whole group on your list but not *every* member this time
— the "I already have lettuce" case for shopping, or "skip step 3 on this run"
for projects. You can exclude individual members for one list only, leaving the
group itself untouched.

## Before you start

- Add the group (or routine / process) to your list first. See
  [Build a saved list](/help/build-a-saved-list).

## Steps

1. Open the list and find the group entry.
2. Expand it to show its members.
3. Tap a member to toggle it off — excluded members are skipped on this list
   only.
4. Save the list.

## What you'll see

The group entry shows how many members are excluded (for example, a count like
*−1*). When you run the list, the excluded members don't appear. The group's
own definition is unchanged, so other lists still include every member.
